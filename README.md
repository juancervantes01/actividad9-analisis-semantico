# Actividad 9: Análisis semántico y gestión de la tabla de símbolos

Proyecto de compiladores desarrollado en Java utilizando **JFlex (v1.9.1)** y **Java CUP (v11b)** para realizar el análisis léxico, sintáctico y semántico, generando una Tabla de Símbolos estructurada y control de ámbitos.
